# 圆锥面 827 的跨空白网格

## 数据与复现

本次只读取用户导出的 `data/performance-validation/level-06/local/Y373/cloud.ply.pcad-analysis`，没有打开原始项目。快照 UUID 为 `84c4f09d-028c-4b90-a6f9-3627c306dd0f`，目标名称为「圆锥面 827」，实际集合 ID 为 675。

元数据和指定面映射确认：该集合仅 7 个点，均没有有效法向；半角约 84.297°。显示网格使用的点全部属于该集合，问题不来自其他集合的顶点。原网格包含 3 个三角形，面积 10999.602，最长边 232.623。

从映射按需加载后，发现一个点离其余点最近也有约 210.95 的距离，其他点最近邻距离约 6.65～33.37。上述远点参与全部 3 个大三角形。

提取工具仅将对应解析方程的 28 个观测写入私有回放文件；控制台只打印元数据与统计。无需将点坐标贴入 AI 上下文。

## 原因

1. 曲面预览的二维参数使用 `(平均半径 × 方位角, 轴向高度)`。圆锥的母线长度与轴向高度相差 `1 / cos(半角)`，本例约 10.063 倍。用于三角化和 Alpha 过滤的距离因此失真，远点在参数空间中显得足够近。
2. 原投影保留观测的轴向高度，再用 `高度 × tan(半角)` 生成径向位置。大半角下，正常的法向误差被放大成明显的径向偏移。
3. 曲面流程将集合内所有点标记为已覆盖，未参与任何保留三角形的点也会被隐藏。
4. 识别阶段最小支持点数针对原候选方程；连通分片及最终点归属竞争会使 UI 集合进一步缩小，发布时仅检查非空。因此该限制不能保证最终每个集合仍有相同数量的支撑点。

此前的边界/内部支撑检查位于平面域生成流程，曲面并未使用它。本次的直接根因是圆锥参数距离和投影失真，不适合仅提高全局最小点数来掩盖。

## 修正与验证

圆锥的纵向坐标改为母线长度，先作正交投影。设轴向高度为 `h`、径向距离为 `r`、半角为 `a`，母线参数为 `s = r sin(a) + h cos(a)`，拟合位置为半径 `s sin(a)`、高度 `s cos(a)`；角向尺度使用平均投影半径。

曲面覆盖标记改为查询实际保留的参数域三角形，兼顾角度接缝和空间抽稀前的原始观测，未覆盖点继续可见。

真实 7 点回放结果：

| 指标 | 原结果 | 修正后 |
| --- | ---: | ---: |
| 原大三角形 | 3 | 0 |
| 显示面积 | 10999.602 | 1192.411 |
| 最长边 | 232.623 | 81.192 |
| 网格覆盖的观测 | 7（原逻辑全部标记） | 4 |
| 远处点被网格引用 | 是 | 否 |

修正后保留 2 个局部三角形，原集合的 7 点及拟合方程不变。该结果证明跨空白桥接已消除，不代表已经证实这些点属于真实圆锥；识别候选的最终几何有效性仍需独立评估。此修改未把平面域的边界/内部检查推广为所有曲面的统一校验。

回归覆盖：旧实现会连接的「六点窄条加一个远点」、正常稀疏九点圆锥、大半角圆锥的法向噪声投影，以及圆柱/圆锥/球面/圆环的周期接缝和完整点覆盖。原实现会触发远点桥接断言，修正后上述测试通过。
