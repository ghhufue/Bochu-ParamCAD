# 表面支持与显示参数

入口为「设置 → 超参数 → 表面分析与显示」。参数写入 `config/analysis.conf`；旧配置缺少新增键时使用默认值，不需要迁移。新增 26 项参数，分为最终成面支持、显示网格、局部密度支撑、相对密度孔洞、边界内部支撑、孔槽边界六组。

## 最低支持点数

此前的限制主要位于候选检测阶段。候选切成连通片、与其他方程竞争点归属之后，最终集合可能只剩 7 点，发布时仅检查非空；曲面预览最低只要求 3 点，因此仍可能显示成面。

现在 `minimum_surface_points` 默认 12，沿用原平面域的成面下限，并统一用于：

1. 原始观测完成归属竞争后的自动识别结果；不足的集合不发布，对应点保持未归属。
2. CAD 失败后保留分析结果的客户端发布路径；验证有效源点 ID 并去重后检查数量。
3. 从旧项目或标注加载的平面、圆柱、圆锥、球和圆环预览；小集合保留标签及观测，显示为点。
4. 支撑域或三角网格的独立连通片；大集合内的一小片三角形也不能借总点数通过检查。

共面组建立前也会先检查各集合的点数，防止几个小集合拼起来绕过最终集合门槛。低于门槛的点不被显示网格隐藏。

候选检测中的 `plane_minimum_support_points`、`cone_minimum_support_points` 等参数仍控制候选方程的支持数量。显式非零设置会保留到检测调用，自动分析配额不再覆盖它们。最终成面门槛独立控制分片和点竞争后的最低数量；若希望最终也至少 30 点，应设置 `minimum_surface_points = 30`。

数学上能穿过少量点的解析曲面，不等于有足够点云支撑的有限面。点数门槛只是必要条件；线状退化、相对密度和边界内部支撑检查仍然生效。

## 常用参数

| 参数 | 默认值 | 调整作用 |
| --- | ---: | --- |
| `minimum_surface_points` | 12 | 提高后，更多小集合和小网格片保留为点；7 点在默认策略下不成面 |
| `mesh_point_budget` | 16000 | 影响显示网格精度与计算量；须不小于最低成面点数 |
| `curved_alpha_radius_multiplier` | 2.5 | 越小越严格地剔除曲面长边，过小会切碎正常曲面 |
| `planar_alpha_radius_multiplier` | 2 | 平面初始支撑域半径；过大会扩大跨空白连边的机会 |
| `density_neighbor_count` | 24 | 局部密度估计的稳定性与局部性 |
| `expected_hole_points` | 20 | 孔洞检测窗口的预期点数；提高后更倾向忽略小的空缺 |
| `hole_density_ratio` | 0.2 | 孔内观测与背景预期的最大比例；越小越难认定为孔 |
| `boundary_dominance_ratio` | 0.8 | 外围边界点达到该比例时，进一步检查内部是否缺少支撑 |
| `minimum_expected_interior_points` | 8 | 防止把本来分辨率就低的面仅因缺少内部点而拒绝 |
| `minimum_interior_support_ratio` | 0.2 | 内部独立占用格数与预期点数的最低比例 |

其余参数的名称、注释及范围可直接在面板和 `analysis.conf` 中查看。除点数与采样预算外，这些参数以局部点间距为基准，不随 mm/m/任意单位直接改变。精度焊接的数值容差和几何求积规则作为实现细节保留，不全部暴露为调参项。

## 保存后的行为

保存修改后的分析参数会使当前显示网格缓存失效，立即按新参数重建；不改变文档点数、分组、撤销历史或已拟合方程。识别阶段的参数在下一次识别或重建调用中使用。旧项目中的小集合标注不会自动删除。

此前「圆锥面 827」的 7 点集合在默认参数下不再产生任何显示三角形；点仍可选择和分析。其圆锥展开距离与投影的修正继续保留，即使显式降低点数门槛，也不能重新出现已定位的距离压缩错误。

边界/内部支撑及相对密度孔洞参数目前控制平面域流程；曲面仍使用各自参数图上的 Alpha 过滤、修正后的圆锥距离及统一最小支撑门槛。它们尚未共用完整的平面域孔洞与内部覆盖算法。
