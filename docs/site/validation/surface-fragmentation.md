# 按面拾取与碎面排查（2026-11-16）

本次在现有按面显示功能上加入最近命中面的拾取和整面高亮，并修正一项可复现的显示网格缺口。识别面片数量、显示三角形数量和 CAD 拓扑面数量是三个不同指标，排查时需要分别记录。

## 点击行为

- 点选模式中，射线先查询当前可见的表面三角形，取最近命中三角形所属的集合。
- 选中集合的整个显示面以橙色覆盖高亮；点击原始点或按点 ID 查询时也高亮其所属的显示面。
- Ctrl / Shift 点击增加面，再次点击已完整选中的面将其移除；点击空白清空选择。
- 没有命中显示面时，沿用原始点的拾取。隐藏的面和高亮覆盖层不参与面拾取。
- 选择不修改点云、拟合参数或文档版本，也不重新三角化。

## 碎面来源与证据

### CAD 闭合失败后显示的检测面片

`PointCloudWorkspaceController::onCadReconstructionFinished` 的 Unsupported 分支调用 `describeAnalysisPatches`，将分析得到的连通面片发布到点云集合。这个回显路径由 `1cda03d` 引入。每个连通面片独立显示，因此 CAD 重建失败后仍然会出现大量彩色面片。

当前版本重新执行已有 20 mm 点云用例：

```powershell
& 'artifacts/build-structured-light/Release/cad_reconstruction_validation.exe' reconstruct-cloud `
  'outputs/captures/20261114_base32_hi/reconstructions/20261114_oriented_surfaces10/downsampled/cloud_20mm.ply' `
  'outputs/surface-picking-validation/cad-replay.json' `
  'outputs/surface-picking-validation/cad-replay.step'
```

结果为 `unsupported` / `cad_constructed=false`：94,148 个输入点，746 个检测面片，17 个候选，0 个闭合候选，101 条开放边。常规识别还报告部分面片缺少材料侧法向。退出码 1 对应该未完成重建的诊断结果。

已有 `outputs/diagnostics/plane_growth/cad_replay.json` 同样记录了 746 个检测面片、17 个候选和材料侧法向错误。此用例没有证据支持“最近的并行优化新增了这些面片”的判断；显示失败重建的证据，让已有的识别分片变得可见。

### 显示网格额外制造采样缺口

`PlanarSurfaceDomain::recoverDomain` 使用局部点间距检查三角形，并仅修补小型封闭缺口。原来的修补面积和跨度限制过紧，正常不规则采样产生的一组相邻拒绝三角形也会保留下来。

新增确定性用例：面积 1,600 的完整平面，41 × 41 个点，内部坐标加入 ±0.4 的采样抖动，边界不变。原显示面积为 1,499.21，损失约 6.30%；调整仅针对有观测支持的小型封闭缺口后，面积为 1,566.62，损失约 2.09%。其余损失仍包含边界附近被保守拒绝的三角形。

修补必须同时满足封闭、有局部观测支持、面积不超过 6 倍局部点间距平方、跨度不超过 4 倍局部点间距。开放缺口不进入修补；已有内孔、外接槽口、远距离共面岛、窄条、线状尾部及密度变化用例全部通过。

## 相对密度成面更新（同日后续）

针对“选中一次能高亮同一面的所有碎片”的现象，进一步更新了 `PlanarSurfaceDomain`。以下逻辑替代前述固定面积的小缺口修补，适用于拟合平面的显示网格。

### 判定流程

1. 精度级重复观测先焊接，再分别使用第 8、12、16 个近邻的距离估计二维面积密度，取稳健中值。近邻距离出现明显跳变时截断，避免把远处岛屿计入采样尺度。
2. 仅在有二维观测支撑的点上平滑密度。采用按代表面积 `1 / density` 加权的截尾对数均值，防止密集区域以点数优势抬高相邻稀疏区域的背景密度。
3. 连通判定结合边两侧的密度尺度。外边界仍由保守覆盖判定决定；可靠的重复短间距限制边缘扩张，非均匀采样则更多采用面积密度。额外检查每条边的中点，避免窄槽恰好落在检查步长之间。
4. 对封闭的内部空区，先积分 `面积 × 背景密度`，判断是否有足够缺失证据。证据不足的采样空隙连续成面。
5. 背景密度从周围已观测点插值，空区自己的近邻半径不参与背景估计。两个局部圆形窗口分别预期 12.8 和 20 个观测；两个窗口内实际点数都低于预期的 20%，才保留密度缺失候选。观察到的点数很少时，这些阈值是分辨率策略，不是经过概率校准的孔洞置信度。
6. 细长内槽补充边界证据：两条持续相对、方向一致的边界可以保留槽口，避免圆形窗口跨过两侧材料后将槽误填。已有外接槽口和分离岛屿保持各自边界。
7. 最终根据已经判定的外边界和孔洞约束三角化。取消输出三角形上的第二次覆盖剔除，避免将已判为正常采样的空隙再次挖开。

密度判断只能确定观测缺失，无法单独区分真实孔洞与扫描遮挡。整体稀疏时，可分辨的最小孔尺寸随之增大。原始点、所属集合、拟合平面及 CAD 实体闭合规则不受该显示更新影响。

### 新增回归用例

- 同一个物理空区在密集采样中保留为孔，在稀疏采样中按正常采样间隙连接。
- 16 倍面积密度差的交界保留一个连通网格，面积 800 / 800。
- 密集平面中的稀疏观测区域连续成面。
- 完整抖动平面覆盖面积从前阶段的 1,566.62 / 1,600 提升到 1,600 / 1,600。
- 固定随机采样用例覆盖 1,586.83 / 1,600，并保持一个连通网格。
- 缩放 0.1、1、20 倍，旋转和平移后的内槽，以及超过 16,000 点的网格预算场景。
- 原有内孔、开放窄槽、共面岛屿、重复点、线状尾部、窄面、拾取及工作区用例继续通过。
