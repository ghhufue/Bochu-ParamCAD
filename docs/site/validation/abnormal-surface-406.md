2026-11-16，从当前客户端另存的 `data/performance-validation/local/Y373/project.pcad` 提取必要证据，使用当前 C++ 成面代码重放。原项目、点云、识别标注和客户端状态未更改。

## 结论

异常显示由“相同方程集合共用成面 + 离群点被当作稀疏采样 + 三角形按顶点多数归属”共同造成。当前代码没有使用独立的面积支撑覆盖率来拦截这类长三角形。相对密度必须建立在可信的局部二维支撑上，不能由单个离群点自行定义尺度。

## 每一步为什么放行

### 识别和标注保留只要求点符合方程，没有面积覆盖门槛

`detection/cgal/PlaneEvidence.cpp` 按点到平面的距离及法向筛选支撑点，并在候选级检查最少支撑点数量。之后 `SurfacePatches.cpp` 按空间连通性分片；`describeAnalysisPatches` 为各片复制原候选的参数、残差和置信度。`PointCloudSelection::addSurfaces` 在处理归属冲突后只排除空集合，因此可以保留一个点的诊断片。

这个单点距拟合无限平面的残差约 2.60458，方程相容并不能证明它与其他点之间存在有限表面。候选的原始 RANSAC 种子和各轮中间支撑集没有保存在项目中，本次没有重新运行当前客户端识别，因此不推断该候选具体来自哪轮随机采样。

### 显示按相同方程合并，没有先排除单点片

`PointCloudSurfaceMesh.cpp` 按规范化后的 `(nx, ny, nz, offset)` 分组，然后把同组点合并成一个网格。这个路径将上述 44 + 1 个点组合起来。共用方程的目的是消除原先的集合缝隙，但不保证两个集合在有限空间上都具有可靠的面支撑。

### 离群点的远邻被解释成“正常稀疏”

按当前 `PlanarSurfaceDomain` 计算过程进行独立的数值核对：该单点前几个邻居距离约为 509.4、511.8、514.2、515.4。它们之间没有明显倍数跳变，所以“距离跳变截断”无法发现单点前面缺少真正的局部邻域。

这个单点得到约 `5.89e-6` 的原始面积密度，支撑半径约 1,160.46；把点本身和远处线状点群一起计算协方差，又使它通过二维支撑检验。密度连接规则允许约 1,000 单位的连边，509 单位的空区遂被跨越。

这不是周围一个可信的稀疏面共同支持的尺度，而是离群点借助远邻制造出的尺度。仅根据该尺度判断覆盖，会把严重缺失误解释成低分辨率。

### 面片归属与点归属不同，选取后显得像“44 点撑起大面”

生成的三角形按三个顶点的多数集合分配。三角形若由平面 406 的两个点和单点 114234 组成，就被显示归给平面 406。点击选面依照这个显示归属选取集合 182 的 44 个源点；它不会把额外顶点改归集合 182，因此选中点数和实际参与网格的点数并不一致。

## 为什么“覆盖率低”没有阻止它

现有几个指标含义不同：

- 检测证据 `coverage = 支撑点数 / 输入点数`，衡量点数占比。它不是面积覆盖率，也没有在此显示路径作为最低门槛。
- 保存的 `confidence = 1 - 平均距离残差 / 距离容差`。这里 0.507 对应平均残差 1.676、容差约 3.400798，不能解释为“50.7% 的面积有支撑”。残差和置信度由原候选继承到片段，未按最终 44 点或 1 点重新校验。
- 之前报告的“95.0% 覆盖率”是原始点被显示网格覆盖的比例。错误的大三角形也能使该数值变高，因此该指标本身不足以证明成面正确。
- 相对密度策略决定局部空区能否补面，但依赖的密度参考已被本例离群点放大，不能替代可信的二维面积支撑检查。

不能简单以“44 / 460,488 很小”为由删除这个集合，小型真实表面也只占全云很小比例。需要拦截的是没有持续横向观测支撑的扩张，允许有支撑的局部窄条继续显示。

## 后续修正应约束的位置

1. 共面分组之前或之中，单点及一维退化片可以作为诊断保留，但不能自行建立面尺度或成为跨片三角形的支撑。
2. 邻域尺度必须来自互相验证的局部采样；不能用远点自己的远邻距离来证明该远点可连接。
3. 二维支撑应检查持续的横向观测，避免离群点自己抬高协方差。不能只用整体长宽比，真实窄条也需要保留。
4. 面片归属应保留桥接顶点的来源，校验最终集合网格的面积支撑，而不是依赖候选的距离置信度。

本次只增加了提取和重放诊断工具，没有修改生产成面规则。常规 `point_cloud_rendering_test` 继续通过，也证明原回归集没有覆盖这个“近似线状点群 + 稍近远点 + 跨集合共面合并”的实际退化情况。

## 边界点与内部点支撑验证

按候选面的各个连通区域分别执行，保留有支撑的局部区域，不因另一个区域错误而丢弃整个拟合平面。

- 从实际外轮廓建立边界距离索引，将内孔边界单独分类。统计去重后的外边界带点、孔边界带点和内部点。
- 边界带宽使用观测点第二近邻间距的中值的一半，独立于前面被密度估计扩大的连接半径。
- 当外边界带点达到 80%，进一步估计扣除边界带后的内部面积。只有面内仍存在足够宽的区域、估算可容纳至少 8 个独立采样位置时，才要求相应的内部观测。
- 内部观测按局部采样单元去重计数，避免重复点或同一位置的大量采样虚增支撑。独立内部单元少于估算容量的 20% 时拒绝该候选域。
- 没有足够分辨率来要求内部点的窄条、小面继续保留。外边界点比例为 100% 本身不意味着面无效。
- 对通过验证的边界统一三角化；被拒绝区域的观测保留为点云，不改变点归属或拟合方程。
