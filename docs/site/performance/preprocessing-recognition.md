# 预处理与曲面识别调优

本轮为预处理中的独立逐点计算增加多线程，并减少 OCCT 重复构建。曲面识别任务已经在后台运行，但 RANSAC 的多族、多区域和多轮恢复仍按顺序调度。

## 当前执行状态

| 阶段 | 内部状态 | 原因或限制 |
| --- | --- | --- |
| 单位转换、体素代表点选择、KD 树构建 | 串行 | 本轮未拆分这些阶段 |
| 离群过滤的逐点 KNN/平均邻距 | **并行** | 每点独立，只读共享索引 |
| 均值、方差、中位数/MAD 和阈值 | 串行 | 保留原浮点计算顺序 |
| 逐点 PCA、曲率和缺失法向 | **并行** | 每点只写自己的结果 |
| 法向符号传播 | 串行 | 优先队列和相邻状态存在依赖 |
| 多尺度 RANSAC 的族、区域与轮次 | 后台串行 | 没有新增检测任务池 |
| 面片连通、关系枚举、装配闭合和投影搜索 | 后台串行 | 后台线程与内部并行是不同概念 |
| 主要 OCCT 布尔及特征历史重建 | 串行 | 去掉重复 Build，没有开启布尔并行 |

## 1. 共享只读索引，并行处理各点

统计离群过滤和局部 PCA 的每个点都可以独立查询邻居。实现共享只读 KD 树，把索引范围分给有界工作线程，按原位置写回结果，不改变点序或 PointId。

离群过滤先并行算各点平均邻距，再按原顺序计算全局均值和方差。PCA 的法向、曲率和退化标记各点独立写出，计数随后汇总。线程连接后传播异常，不把部分成功的结果提交给文档。

默认自动最多 8 个工作线程，小点集会退回串行。通过 `preprocessing.conf` 的 `worker_count=1` 可强制串行；完整规则见[并发与串行状态](/performance/execution-model#线程数与串行回退)。

| 完整预处理，包含方向传播和指纹检查 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 100,000 点 | 1015.04 ms | 559.97 ms |
| 400,000 点 | 5155.33 ms | 3191.88 ms |

这是完整预处理的收益，不是只测 KNN 查询的加速比。方向传播、建树、体素等串行部分仍限制整体速度。

## 2. 保持方向传播和过滤规则

PCA 只估计法向轴，材料内外方向仍从已知带符号观测出发，通过多源最短路径传播。不能直接并行修改同一优先队列及相邻节点状态，也不能用统一世界方向替代这一算法来换取速度。

原始法向符号、保护点、薄壁和退化邻域规则均保留。回归测试对比串行与并行的点指纹、曲率、过滤阈值和全部统计，并覆盖输入顺序反转。离群点移除前后的点集不同，也不能不校验快照就跨阶段复用同一 KD 树。

## 3. RANSAC 仍按族、区域和恢复轮次顺序执行

`MultiScaleDetector.cpp` 的全局检测按启用曲面族依次调用，局部恢复再遍历区域和曲面族。后续残余点取决于已分配支持点，因此恢复轮次之间有数据依赖。

项目尚未把同轮区域或不同曲面族放入并行任务池，也没有共享一个可变 CGAL 输入供多个任务同时重排。未来可以评估独立 region/family 并行，但要保持独立检测器、随机流、稳定合并顺序和内存上限。当前不能把这项计划写成已完成。

## 4. 关系推断移出界面线程

关系推断先建立只包含坐标、集合、删除标记和曲面描述的独立快照，在后台计算，再回到 GUI 检查文档版本和距离/角度容差后提交。

内部的关系枚举仍是串行，已经存在的包围盒邻接剔除和去重规则继续保留。手动关系、抑制记录和稳定关系 ID 不会因为后台计算而丢失；取消、容差变化或期间编辑会使旧结果失效。

## 5. OCCT 布尔只构建一次

此前部分路径使用带两个 Shape 的 Fuse/Cut/Common 构造函数，再设置选项并调用 Build；构造函数已经执行过一次构建。现在改为空构造、设置输入和选项、执行一次 Build，并覆盖需要 fuzzy tolerance 的轮廓融合路径。

主要布尔调用继续使用 `SetRunParallel(false)`，实体校验、体积检查和失败回滚保留。六孔 CAD 构建及校验从 26.18 ms 降到 17.63 ms，收益来自少做重复工作，而不是新增建模线程。

最终 CAD 特征提交和显示三角化仍有 GUI 主线程工作；后台得到识别候选，不代表最终几何已经在后台全部准备完成。

## 后续重点

投影候选仍可能重复重放相同特征前缀，评分仍使用精确 B-Rep 距离；虽然已有评分点数和搜索预算，候选数仍会放大成本。前缀缓存、粗筛、按候选并行和增量历史重建需要单独验证，当前均未计入本轮收益。

代码入口位于 `core/geometric_reconstruction/src/preprocessing/`、`common/Parallel.h`、`detection/MultiScaleDetector.cpp`，以及 `core/parametric_modeling/src/occt/BooleanInputs.h` 和 `RebuildEngine.cpp`。
