# 性能调优

本栏目记录 2026-11-15 优化版的实施内容、实测收益和当前执行模型。内容依据本地已构建并通过回归的优化工作树；阅读时应核对实际使用的客户端版本，历史发布包不一定包含这些改动。

这轮优化主要减少重复计算、主线程阻塞、大数组临时内存和交互期渲染开销，并对适合拆分的计算使用有界工作线程。

## 已测得的变化

| 场景 | 优化前 | 优化后 | 收益 |
| --- | ---: | ---: | ---: |
| 10 万点完整预处理 | 1015.04 ms | 559.97 ms | 1.81× |
| 40 万点完整预处理 | 5155.33 ms | 3191.88 ms | 1.62× |
| 六孔 CAD 构建及校验 | 26.18 ms | 17.63 ms | 1.48× |
| 拖动时材质预览帧耗时 p50 | 11.05 ms | 3.04 ms | 3.63× |
| 1280×960 法向估计 | 4.958 s | 1.536 s | 3.23× |
| 同一法向基准的进程峰值内存 | 2.376 GB | 0.570 GB | 减少约 76% |

拖动预览临时使用较低分辨率的阴影，停止操作和截图时恢复完整质量。上述值是各自基准场景的结果，不能相乘得到整条重建链路的加速比；已有低分辨率扫描回放也没有观察到可靠的显著提速。完整条件见[性能基准](/performance/benchmarks)。

## 当前并发能力速览

| 已有内部并行 | 后台运行、计算仍主要串行 | 主线程或显式串行 |
| --- | --- | --- |
| C++ 统计离群过滤的逐点 KNN | 曲面关系推断 | VTK/OpenGL 上下文操作和渲染提交 |
| C++ 局部 PCA、曲率和缺失法向计算 | 降采样的读取、排序融合和写盘 | 法向方向传播和浮点统计归约 |
| 大点图的 Python 法向行块计算 | CAD 识别的任务编排 | 曲面族、残余恢复轮次及局部区域的 RANSAC 调度 |
| GPU 执行渲染内核 | Python/COLMAP/Mitsuba 子进程与界面独立运行 | 结构光站点、曝光、图案循环；主要 OCCT 布尔路径 |

“后台”表示界面线程可继续处理事件，不代表算法使用多个 CPU 核。不同任务也不是全部同时运行：同一工作区的 CAD 计算、点云分析、关系推断和降采样有忙碌状态及互斥检查。详细条件和例外见[执行状态表](/performance/execution-model)。

## 正确性与后续范围

本轮优化版的 **38 项 C++ 测试和 28 项 Python 测试全部通过**。预处理指纹、法向输出及保存的扫描点云与基线保持一致；还验证了取消、过期结果拒绝、工程保存恢复、语义面拾取和完整质量渲染恢复。

多尺度 RANSAC 任务池、投影候选前缀缓存、精确评分粗筛、GPU 内部阴影传递和大点云显示 LOD 仍是后续方向，未计入已实现或已测得的收益。
