# 装配分组与壳闭合

装配路径只在“无模板、无人工关系，且常规识别失败或候选多体”时触发。它把全量观测分解为面片、部件和边界，再尝试闭合成实体；只有闭合候选会进入建模，开放部件和诊断仍保留。实现集中在 `core/geometric_reconstruction/src/recognition/assembly`。

## 面片连接与点归属

`AssemblyReconstruction.cpp` 的 `extractPatches` 要求毫米单位、点数不少于 24、邻域数在 6 到 128 之间、法向角不超过 45°。工作点超过 200000 时按坐标哈希截断，使预算与文件顺序、ID 顺序无关；随后按坐标排序并补估缺失法向。每个点的局部间距取同向邻域中第三个切向邻居的距离；用户在配置中给出的容差为 0 时，容差取 $\max(10^{-6}D,\;3Q_{25})$，$D$ 为包围盒对角线，$Q_{25}$ 为法向偏移的 25% 分位数。

区域生长同时检查四项：法向夹角、连接距离、平面偏移、是否穿越已观测边界。连接半径是 `connectivity_factor × max(spacing)`，偏移不得超过公共容差；`crossesObservedBoundary` 会沿端点连线寻找法向近似垂直的“墙点”，若交点落在该点邻域内则拒绝连接。这一检查是启发式，薄壁与锐边仍可能泄漏。生长后不足 24 点的区域被丢弃，不产生面片。

面片法向由成员点协方差的最小特征向量重新估计，并与平均法向对齐符号；残差 RMS 不超过容差记为平面面片。平面测试留下的曲面残差再按局部法向光滑性生长，形成非平面面片。未被任何面片接受、但方向未知的点，会按平面残差在 3 轮内挂接到邻近平面面片；仍无法归属的点保持未分配。

`groupPatches` 遍历不同面片之间的相邻点对：法向几乎相同（$|\mathbf{n}_a\cdot\mathbf{n}_b|>0.995$）的对不参与连接；连接凸性要求两个面片法向都朝向对方，且位移在 $2\times$ 容差内。并查集合并条件是连接数不少于 3 且凸连接比例不低于 0.7；方向未知时只要求连接数。凹接触与粘连仍可能合错或过分割，代码不保证部件等于真实零件实例。

点归属有两种独立口径：`workingPointIds` 表示装配采样归属，`pointIds` 表示全量回填归属。`assignSourceObservations` 对每个全量点查找最近的 4 个工作点，要求距离在 `2 × connectivity_factor × spacing` 内且法向对齐；找不到就进入未分配集合。回填发生在边界恢复之后，因此边界使用的是工作面片，而统计覆盖率使用全量观测。

## 有限边界与共边

`FiniteBoundaries.cpp` 只处理平面面片。支持点投影到面片局部二维坐标后做 CGAL Delaunay 三角化，按外接圆半径过滤得到 Alpha Shape；半径取 $\max(2\varepsilon,\;2.5\times\text{spacing})$。只被一个三角形使用的边连成边界环，自交环会被拆分为简单环，再用与间距相关的容差做折线简化。

简化后的环要与相邻面片的平面交线吸附：交线在局部坐标中表示为直线约束，顶点在 `reach = max(4ε, 2.5 × spacing)` 内移动到约束上。吸附前后都要比较拓扑；环数量、包含关系或自交状态变化时，回退到未吸附版本并记录一次拓扑回退。稀疏采样会让半径过大而粘连，或过小而使边界断裂；回退只能避免错误简化，不能恢复未观测的轮廓。

面片可以有多个环：一个外环加若干内环表示孔，独立的正面积内环表示分离岛。闭合阶段若发现除首个环外还有正面积环，会以“边界岛仍存在歧义”拒绝该部件，因为当前闭合器无法判断岛属于材料还是孔。

闭合时若用支撑平面的凸包重写轮廓，原观测环会保存在 `boundaryBeforeClosure` 中，并记录修订来源（凸支撑平面或合并共面面片）；被合并的共面面片只保留修订记录，不再保留旧环。这样轮廓修订不会抹掉“观测曾经是什么”，只是把闭合结果作为新版本。

## 闭合判定与部分结果

`PartClosure.cpp` 的凸支撑平面法要求每个面片都是平面，面片数在 4 到 32 之间。共面面片先合并为支撑平面：法向夹角余弦不低于 0.9998，偏移在 $2\times$ 容差内，且所有支持点都在 $4\times$ 容差内一致。少于 4 个支撑平面直接失败。

支撑平面集合必须没有 recession ray，否则说明存在未观测的开口方向，部件保持开放。顶点由三个平面求交得到，并要求满足所有半空间约束；重合顶点按 $4\times$ 容差焊接。每个支撑面上的顶点投影后取凸包形成环。随后用入射面方程做 QR 最小二乘精修顶点，并在长边上插入其它面的顶点，显式处理 T-junction。

边图判定使用无向边的使用次数与方向：使用 1 次是开边，使用次数不为 2 或方向和不平衡是非流形边。只有开边数与非流形边数都为 0 才继续。接着检查方向已知、三维跨度大于容差、构建 `ProfileBodyParams` 并交给 OCCT 试建。若实体内部存在大量观测点，则判定材料冲突：阈值是 $\max(2,\; \text{点数}/200)$，冲突点需要离所有面片边界超过焊接容差。

闭合状态与原因会逐部件保留：

| 状态 | 含义 |
| --- | --- |
| `open` | 边界尚未形成闭合壳，或半空间存在开口方向 |
| `ambiguous` | 面片数超过闭合预算（128）或顶点数超限 |
| `orientation_unknown` | 材料法向未建立 |
| `closed_boundary` | 边图闭合但关闭了实体试建 |
| `invalid_shell` | OCCT 构体失败 |
| `material_conflict` | 实体内部观测与实心假设矛盾 |
| `closed_solid` | 通过边界与材料检查的平面壳体 |
| `closed_primitive` | 通过端面与角度覆盖检查的解析曲面体 |
| `closed_projection` | 开放部件经投影拟合闭合 |

曲面体闭合复用 `reconstructCurvedSolid`，要求局部样本数在 80 到 20000 之间、覆盖率 0.95，并对实体内部做同样的材料冲突检查。专用恢复路径（解析轮廓、环形管、圆盘体、局部轮廓）失败时不会伪造闭合，只会保留状态与原因。

装配结果允许部分成功：已闭合部件进入候选，开放部件与未分配点保留在 `AssemblyReconstructionResult` 中。若一个部件都没有闭合，生产任务返回 `Unsupported`，但点云视图仍显示分组、边界与开放部件。开放部件在点数不少于 60、面片数不少于 2 且投影回退开启时，最多取 6 个尝试投影拟合；拟合成功会把部件标记为 `closed_projection`。这不改变“部分结果”的性质，只是把二维挤出作为另一类候选证据。
