# 二维轮廓与投影评分

投影路径用于未闭合但有足够观测的部件：它沿候选轴把三维点压成二维截面，生成挤出与切除操作，再做临时试建与统一评分。实现位于 `core/geometric_reconstruction/src/parts/projection`，对外入口是 `fitProjectionExtrusion`。这条路径只表达挤出类操作，不处理旋转、扫掠或放样。

## 候选轴与截面观测

`prepareProjection` 要求毫米单位、点数不少于两倍最小端面点数（默认 12）。拟合点按坐标排序后等间隔抽样，上限 24000；评分视图另做一次体素化再抽样，上限 1800，所有候选共享同一视图，因此分数可比。距离容差在配置为 0 时取包围盒对角线的 0.25%。

候选轴来源包括圆柱轴、平面法向、点云 PCA 主轴、侧平面法向的两两叉积，以及侧壁法向矩的最小特征向量。侧壁矩只纳入法向与当前轴夹角余弦绝对值不超过 0.2 的点，且要求矩矩阵的特征值间隙超过 $0.03\lambda_2$。轴去重使用 $|\mathbf{a}_i\cdot\mathbf{a}_j| \ge 0.9986$，总数上限 12；`include_area_directions` 默认关闭，面积方向不参与。

每条轴建立局部坐标系后，沿轴深度排序并去掉两端各 0.2% 的分位数，得到拉伸区间与凸包投影面积。端面点需满足深度在边界 $3\varepsilon$ 内且法向与轴余弦不低于 0.9；点数少于 12 时端面为空，该轴在单轴路径中被跳过。端面深度取支持点深度的中位数，而非极值，以避免毛刺拉长实体。

## 外环、内环与轮廓简化

端面点投影到草图平面后交给轮廓拟合：端面草图的外环来自 Alpha Shape，半径取 $\max(1.5\times\text{spacing},\,3\varepsilon)$；简化容差默认等于距离容差。一个截面只允许一个连通外环，出现第二个连通区域时直接失败，因为 CAD 草图的一次拉伸只消费一个区域。

外环先尝试圆拟合。设计矩阵为

$$
2x_i a + 2y_i b + c = x_i^2 + y_i^2
$$

用列主元 QR 求解圆心与半径。拟合要求至少 8 个顶点、半径不小于 $5\varepsilon$、所有顶点到圆距离不超过容差、相邻顶点最大角间隙不超过 60°。任一条件不满足就退化为 `Line2D` 折线；折线边数超过 80 时返回空，不生成草图。

内环不会仅凭“中间有空洞”就成为孔。代码在深度方向划 5 个带，去掉两端各 10%，只统计法向接近径向（$|\mathbf{n}\cdot\mathbf{u}| \le 0.3$）的点；至少 3 个带、每带至少 2 个点，内环才被接受为孔。圆柱证据还可以直接补孔：角覆盖不低于 0.8、轴与候选轴对齐、圆柱两端落在端面带 4ε 内、孔心在外环内部、外环顶点与孔心距离大于半径加 2ε、端面内部没有点落在半径减 2ε 内。重复孔按 2ε 去重，对应的圆形外环会被移除。

这种“外环 + 有壁证据的孔”的表达能力有限：椭圆、样条、圆弧过渡与自由曲线截面都不支持；内环缺少侧壁观测时会被丢弃，而不是猜测为孔。

## 操作提案与搜索

基体提案由首端面或末端面轮廓沿轴拉伸，深度为两端面深度差；中截面来自与轴对齐的平面证据，距两端至少 5ε、彼此在 4ε 内合并，最多 2 个。分段路径把首段与末段分别拉伸，第二段改为 `Join`；两轴求交路径则把两个包络拉伸的第二个操作改为 `Intersect`。

切除提案包括：

- 直槽：轮廓必须恰好 4 条 `Line2D`，每条边要有法向对齐 0.95 的侧壁点，点数不少于 6，侧壁深度覆盖不少于槽深的 0.6，至少 2 条边有支撑；切除深度额外加 1ε 过切。
- 盲孔：角覆盖不低于 0.65，底面与开口面各有足够的端面点，深度大于 3ε。
- 通孔：两个开口都要有观测，端面带内不得有“堵住”的点，内壁内向点不少于 12，且外向点比例受限。

搜索以单轴基体程序为起点，Beam 宽度为 4，最大操作数为 3。扩展一个操作需要同时满足：体积变化超过 $\varepsilon^3$（切除与求交取负号）、并且“完成所需步数”“新变为可接受”或“分数改善至少 0.01 且内点率不下降”三者之一。搜索结束后会尝试删去冗余操作，只要剩余程序仍可接受且分数不升。两轴求交要求两轴夹角余弦不超过 0.5；最终状态分为 `Accepted`、`InsufficientSupport`、`NoValidBase` 与 `Cancelled`。

搜索不是穷举：Beam 截断可能错过更优序列，3 步上限也无法表达复杂零件。没有有效基体时返回 `NoValidBase`；有基体但解释不足时返回 `InsufficientSupport`，并保留拒绝操作供调试页显示。

## 评分指标与候选选择

试建通过 `buildProjectionProgram` 逐条执行草图与拉伸，任一操作失败、结果不是单一有效实体或体积非正即放弃该候选。评分用 `BRepExtrema_DistShapeShape` 计算每个观测点到候选实体所有面的最近距离，并统计：

| 指标 | 计算口径 |
| --- | --- |
| 体积 | OCCT 体积属性 |
| 中位距离 / P95 距离 | 全部评分点距离排序后的分位数 |
| 内点率 | $1-\text{残差点数}/\text{评分点数}$，残差定义为距离大于容差 |
| 法向平均误差 | 点命中面时，面法向与点法向夹角（度） |
| 无支持面面积比例 | 支持点少于 3 个的面的面积和 / 总面积 |
| 总分 | 平均距离损失 + 无支持面积比例 + 操作惩罚 + 曲线惩罚 |

距离损失对每个点取 $\min(d/\varepsilon, 8)$，避免单个极端点主导总分；法向项按 $0.5(1-\cos\theta)$ 累加。支持点的判定同时要求距离不超过容差、法向对齐不低于 0.8；方向未知时取绝对值。操作惩罚为每步 0.015，曲线惩罚为每条草图实体 0.001。

候选通过门槛是：内点率不低于 0.9、P95 距离不超过 $3\varepsilon$、无支持面面积比例不超过 0.04。三个条件同时满足才算 `Accepted`，否则即使总分更低也归为支持不足。

评分视图固定为最多 1800 个点，是采样评估而非全量评估；它比较的是“同一视图下的解释力”，不是物理测量精度或公差分析。评分也不检查实体内部是否存在矛盾观测，体积占据与内部冲突由装配闭合或后续建模模块负责。
