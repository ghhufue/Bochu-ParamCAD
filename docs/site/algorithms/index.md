# 算法原理

本栏目记录后台 CAD 重建链路中各级算法的**可观测证据、判定条件与失效边界**，而不是对论文方法的复述。每一页都对应现行代码：阈值来自 `apps/ParamCAD Studio/config/*.conf` 的默认值，几何公式对应 `core/geometric_reconstruction/src` 中的实际计算，拒绝条件对应代码里的显式跳过、错误返回或状态标记。

算法的输入始终是观测快照与其中的源点 ID；中间产物是曲面证据、有限面片与关系；最终产物是候选，以及绑定当前修订的建模补丁。识别成功不等于 B-Rep 一定生成成功——候选仍需经过特征历史的原子提交，才可能成为可导出的实体。这条边界贯穿本栏目所有页面。

阅读时请区分三类陈述：代码中可以直接验证的判定（例如“少于 6 个平面候选直接失败”）、由配置给出的默认阈值（例如角度容差 5°）、以及工程上的经验取舍（例如 Alpha Shape 半径对稀疏采样敏感）。第三类只是当前实现的适用范围，不构成精度承诺。

## 证据链与术语

整条链路的术语按固定口径使用，避免同一现象在不同模块被赋予不同含义：

- **观测快照**：只做单位换算的全量点集合，保留源单位、缩放比例与指纹；删点或跳过非有限坐标都不重新编号。
- **源点 ID**：客户端按原文档行号加一生成，是跨模块追溯观测的唯一键。
- **曲面证据**：某个解析基元的方程加支持点集合，可能只是部分面、重复面或伪面。
- **有限面片**：把证据的支持点按空间连通性生长后得到的有限区域，带质心、包围盒与材料法向。
- **关系**：面片之间的邻接、平行、垂直、共面、同轴、相切等成对约束，可被关系优化和人工关系复验使用。
- **候选**：识别模块输出的几何假设，尚未写入模型。
- **建模补丁**：绑定预期修订的有序命令集合，由建模核心原子应用；失败即整体回滚。
- **特征历史**：按顺序重放的特征记录，B-Rep 由它重建，而不是由候选直接生成。

这些对象各自有独立的作用域：基元 ID 与面片 ID 只在一次分析快照内有效，装配面片与部件 ID 只在一次分解内有效，候选只有转成建模补丁后才引用模型修订。跨快照复用证据会直接失败，代码用点云指纹校验这一点。

## 阅读顺序

初次阅读建议按“输入—证据—判定—成型”推进：先看多视角几何理解快照来源，再看点云处理理解源点 ID、保护点与法向状态，然后看解析拟合理解曲面证据的置信度与覆盖率，最后看特征判定、壳闭合与投影评分理解三类候选路径。

如果只关心某类零件的失败原因，可以按现象跳转：

- 箱体或组合体被判失败：看 `/algorithms/feature-inference` 中的六面配对、材料单元与边界一致性。
- 多体只分组不闭合：看 `/algorithms/shell-closure` 中的半空间求交、开边与非流形判定。
- 投影调试页只有拒绝诊断：看 `/algorithms/projection-scoring` 中的评分门槛与搜索状态。
- 预处理后法向大量未定向：看 `/algorithms/point-cloud-processing` 中的定向传播与退化邻域。
- 图像重建尺度不确定：看 `/algorithms/multiview-geometry` 中的外参缺失与退化场景。

## 与模块手册的分工

模块手册（如 `/modules/surface-detection`、`/modules/assembly-reconstruction`）按调用顺序和接口描述“谁调用谁、输入输出是什么”。算法页只回答“为什么这样判定、在什么条件下失效”。同一个阈值可能在两处出现，但算法页给出推导口径，模块页给出调用位置。

配置项的完整含义见 `/development/configuration-cli`。本栏目只引用与判定边界直接相关的默认值；运行时可被超参数配置覆盖，因此文中数字应理解为当前默认口径，而不是硬编码常量。阶段契约与回归用例见 `/validation/contract-tests`，那里记录的是可复现的输入输出，而不是算法解释。

## 边界声明

本栏目不描述尚未实现的能力，也不把参数调整描述成通用解法。当前代码对以下情况仍没有通用支持：严重遮挡与缺面、圆角与倒角过渡、自由曲面与 NURBS、任意凹多面体、多材料零件，以及“拆出的部件必然等于真实零件实例”的保证。相关模块可能给出局部候选，但这些候选的解释力受观测覆盖限制。
