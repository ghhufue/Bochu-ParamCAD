# 路线图与里程碑

本页按根 `README.md` 的进度表概括当前能力和后续方向，状态以当前工作树为准。路线图描述的是工作重点，不是交付承诺；具体缺陷和任务通过 GitHub Issues 跟踪，本页不引用可能过期的编号。

## 开发中

- **结构光钢材物理验证**：Mitsuba 路径追踪已实现并随包分发，间接反射对照已完成；加强筋凹角覆盖率随反射深度增加而下降，说明缺测来自反射与投影几何，而不是采样不足。仍需真实钢材光学参数、实物相机/投影器标定和计量级真值，暂不宣称可重建光亮钢件。

- **通用机械零件特征恢复**：缺面、遮挡、多零件、盲孔、凸台、口袋等组合仍未完成；根 README 将其标记为“进行中”。
- **不完整可见面与全局约束**：需要处理只观测到部分表面的实体，并在多特征之间引入更完整的几何约束。
- **对象分割与多零件装配**：旧装配链的面片提取、分组、边界恢复和壳闭合仍然可用，但只在离线显式 `--legacy-assembly` 时进入生产重建；默认实体推断的多部件覆盖仍受组合搜索预算限制。
- **实拍贯穿孔漏检**：真实拍摄的通孔样本在当前版本仍可能漏检；相关边界见根 `README.md` 和 `ThroughHoleRecognizer` 的判定条件。
- **人工引导的覆盖面**：模板选区、人工关系和局部恢复已接入工作区，但自动识别失败后的通用补全仍依赖有限候选。

## 规划中

| 方向 | 当前基础 | 尚缺内容 |
| --- | --- | --- |
| 自由自然语言 | 已有限定中文参数语法，支持绝对尺寸、增减量和百分比。 | 开放语义、多个目标、拓扑修改和歧义消解。 |
| LLM / Agent | 当前解析完全本地、确定性，未接入模型服务。 | 模型调用、提示与结果校验、失败回退。 |
| 重新拟合 | 自动识别与投影拟合已有固定入口。 | 从文本或局部选择触发重拟合，并与手动修改保护协调。 |
| 跨会话撤销 | 撤销/重做保留在当前会话，`.pcad` 不保存撤销栈。 | 持久化编辑历史或可重放的命令日志。 |
| 工程 schema 迁移 | 读取兼容 version 1/2/3/4，写入按内容选择版本。 | 通用迁移框架和未来版本升级路径。 |
| OBJ/PLY 网格解析 | 当前导入 STEP/STP 和点云 PLY。 | 真实 OBJ/PLY 三角网格解析、显示与后续处理。 |

这些方向都依赖现有边界：新的文本或模型入口必须生成结构化提案，由建模核心校验并原子提交，不能绕过修订检查直接修改 B-Rep。

## 近期优先级

根 README 给出的后续重点集中在四处：

1. 补充带真值的真实机械采集数据，覆盖真实照片噪声和遮挡；
2. 处理不完整可见面、对象分割和全局几何约束；
3. 扩展盲孔、凸台、阶梯轴和口袋等特征恢复；
4. 在已验证的中文参数提案入口上扩展自由自然语言理解与重新拟合。

## Issues 与 Projects

缺陷、功能请求和验证失败使用 GitHub Issues 跟踪，仓库地址见站点页脚和 `docs/.vitepress/config.mts` 的社交链接配置。提交问题时建议附上：

- 使用的提交或版本，以及客户端 `--version` 输出；
- 复现命令、输入数据类型和关键配置覆盖（不要把整份环境打包上传）；
- 对应模块 CLI 的 `--report` JSON，或客户端日志中的错误文本；
- 问题属于采集、重建、检测、识别、装配、投影、建模还是持久化阶段。

本页只维护能力层面的状态，不复制 Issue/PR 编号，也不假设存在公开的 Projects 看板。能力状态变化时，应在同一提交中更新根 README 进度表和本页；若某方向尚未开始，保持“规划中”而不是提前写入“已实现”。
