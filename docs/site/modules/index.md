# 模块手册

本手册按当前代码职责拆分模块，覆盖从虚拟拍摄、COLMAP 重建、点云预处理、曲面证据到识别、装配、投影、建模和持久化的完整链路。每个模块页只描述已实现的能力、实际入口、数据契约和已知边界，不把计划中的接口写成现状。

页面中的距离和阈值默认以毫米为单位，只有明确标注时才使用其他单位。数字来自代码、`apps/ParamCAD Studio/config/*.conf` 或 README；没有代码依据的数值不会被写入。

## 阅读方式

- **职责与入口**回答“这个模块做什么、从哪里进入”。
- **输入与输出**列出调用方必须准备的数据和可以依赖的产物。
- **核心数据结构与依赖**说明跨模块传递的类型、ID 语义和第三方边界。
- **主题章节**展开该模块的关键算法或流程。
- **源码位置**给出 4–8 个可以继续阅读的关键文件。
- **已知限制**只记录当前实现真实存在的边界，不包含路线图愿望。

术语在全部页面中保持一致：观测快照、源点 ID、曲面证据、有限面片、关系、候选、建模补丁、特征历史、修订、原子提交、B-Rep。

## 采集与重建

| 模块页 | 一句话职责 |
| --- | --- |
| [虚拟拍摄与相机元数据](./capture) | 在 VTK 视口中离屏渲染 STEP 模型，输出多视角 PNG、逐图 sidecar 和 manifest v2 相机元数据。 |
| [COLMAP 图像重建](./image-reconstruction) | 以无界面 Python 流程调用 COLMAP 4.2.0，把图片目录和可选 `CameraInfo` 转换为稀疏或稠密彩色 PLY。 |

这两个模块只负责把模型变成图像、再把图像变成点云。它们不判断零件语义，也不生成 CAD 特征。

## 点云与曲面

| 模块页 | 一句话职责 |
| --- | --- |
| [点云输入与预处理](./preprocessing) | 读取 PLY、统一已知单位到毫米，执行稳健体素降采样、统计离群过滤、PCA 法向与曲率估计和方向传播。 |
| [曲面检测与证据](./surface-detection) | 用 CGAL Efficient RANSAC 提议平面、圆柱、球、圆锥和圆环，输出带支持点、残差、覆盖率和置信度的曲面证据。 |
| [曲面分析与修复](./surface-analysis) | 把证据拆成有限连通面片，推断并优化平行、垂直、同轴等关系，提供局部观测恢复和修复事务。 |

这一组是点云到 CAD 的核心几何层。检测输出仍是“证据”，只有经过面片索引、关系推断和实体识别后才能成为候选。

## 识别与装配

| 模块页 | 一句话职责 |
| --- | --- |
| [实体识别与人工引导](./feature-recognition) | 从分析快照识别组合长方体、平面加强筋、贯穿孔和独立曲面实体，并支持模板选区与人工关系引导。 |
| [装配分离与闭合](./assembly-reconstruction) | 在常规识别不适用时提取装配面片、分组件、恢复观测边界并尝试壳闭合，输出部件候选或开放部件。 |
| [轮廓恢复与投影拟合](./projection-fitting) | 从观测轮廓生成拉伸轴与二维截面，搜索加材、切除和盲孔操作序列，并以固定评分视图验证试建实体。 |

识别结果统一表示为 `CompoundCandidate`，它仍是建模提案；能否成为实体由后续建模补丁决定。

## 建模与持久化

| 模块页 | 一句话职责 |
| --- | --- |
| [参数化建模与 B-Rep](./parametric-modeling) | 维护参数化特征历史，在 OpenCASCADE 上重放草图、拉伸、布尔和语义特征，重建 B-Rep 并原子提交建模补丁。 |
| [桌面工作区与参数编辑](./studio) | 提供 Qt/VTK 工作区、后台任务编排、特征面板、参数编辑和限定中文文本修改。 |
| [工程保存与 STEP 导出](./persistence) | 保存和恢复 `.pcad` 工程，导出当前实体为 STEP，并在重开后继续编辑特征历史。 |

## 与端到端流程的对应

```text
STEP / 真实零件
  → 虚拟拍摄（capture）
  → 图像重建（image-reconstruction）
  → 点云预处理（preprocessing）
  → 曲面证据（surface-detection）
  → 面片与关系（surface-analysis）
  → 实体识别（feature-recognition）
  → 装配／投影回退（assembly-reconstruction / projection-fitting）
  → 建模补丁与 B-Rep（parametric-modeling）
  → 工作区编辑与持久化（studio / persistence）
```

采集与重建只产出点云和相机清单；点云与曲面只产出证据、面片和关系；识别与装配只产出候选；建模核心才把候选转换为可编辑的特征历史和 B-Rep。任一阶段失败时，上游产物保持不变，错误沿调用方返回。

## 术语约定

- **观测快照**：一次输入的全部源观测、单位和指纹；任何点或单位变化都会使依赖它的分析失效。
- **源点 ID**：客户端原文档行号加一，降采样、离群过滤和修复合并都不会重新编号。
- **曲面证据、有限面片与关系**：证据是拟合出的解析面，面片是该面在观测上的有限连通支持，关系是面片之间的几何假设。
- **候选与建模补丁**：候选是识别结果，仍是提案；只有绑定当前修订并完成原子提交后，才会进入特征历史并重建 B-Rep。

## 使用建议

- 先读 [系统分层与依赖](../architecture/system-layers) 和 [数据契约与坐标约定](../architecture/data-contracts)，再进入具体模块。
- 只关心图像到点云时，读采集与重建两页即可；只关心点云到 CAD 时，从点云预处理读到参数化建模。
- 想复现一条完整链路，按 [点云到 CAD 快速上手](../getting-started/first-reconstruction) 或 [从多视角图像生成点云](../getting-started/images-to-cloud) 操作。
- 调整阈值前先阅读 [超参数配置与 CLI](../development/configuration-cli)，确认配置优先级和单位。
- 需要核对回归覆盖时，参考 [阶段契约与回归测试](../validation/contract-tests)。
- 排查失败时先确认当前阶段属于哪个模块，再对照该页的“输入与输出”和“已知限制”，避免把识别候选当成已提交实体。
