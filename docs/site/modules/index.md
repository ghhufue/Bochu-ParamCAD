# 模块手册

本手册分为“图像构建点云”和“点云转参数化模型”两部分。点云转模型按五个职责组织阅读：曲面分割、曲面拓展与验证、特征与实体识别、多体分组与闭合、参数化建模与交付。各详细页保留实际接口、数据契约与已知边界。

页面中的距离和阈值默认以毫米为单位，只有明确标注时才使用其他单位。数字来自代码、`apps/ParamCAD Studio/config/*.conf` 或 README；没有代码依据的数值不会被写入。

## 阅读方式

- **职责与入口**回答“这个模块做什么、从哪里进入”。
- **输入与输出**列出调用方必须准备的数据和可以依赖的产物。
- **核心数据结构与依赖**说明跨模块传递的类型、ID 语义和第三方边界。
- **主题章节**展开该模块的关键算法或流程。
- **源码位置**给出 4–8 个可以继续阅读的关键文件。
- **已知限制**只记录当前实现真实存在的边界，不包含路线图愿望。

术语在全部页面中保持一致：观测快照、源点 ID、曲面证据、有限面片、关系、候选、建模补丁、特征历史、修订、原子提交、B-Rep。

## 一、多视角图片构建点云

| 模块页 | 一句话职责 |
| --- | --- |
| [虚拟拍摄与相机元数据](./capture) | 在 VTK 视口中离屏渲染 STEP 模型，输出多视角 PNG、逐图 sidecar 和 manifest v2 相机元数据。 |
| [COLMAP 图像重建](./image-reconstruction) | 以无界面 Python 流程调用 COLMAP 4.2.0，把图片目录和可选 `CameraInfo` 转换为稀疏或稠密彩色 PLY。 |
| [编码结构光与投影拍摄](/modules/structured-light) | VTK 投影光照采集编码序列，由客户端调用 Python 解码、三角化和多站融合，输出毫米单位点云。 |

这些模块负责把模型变成图像、再把图像变成点云。它们不判断零件语义，也不生成 CAD 特征。

## 二、点云转参数化模型

先读[点云转参数化模型：五个模块](./point-cloud-to-cad)，了解每个阶段回答的问题、产物，以及分支何时发生，再进入接口细节。

| 职责模块 | 要理解的问题 | 详细页面 |
| --- | --- | --- |
| 1. 曲面分割 | 点属于哪些面？面是什么几何类型？ | [输入与预处理](./preprocessing)、[分割与几何类型拟合](./surface-detection) |
| 2. 曲面拓展与验证 | 哪些观测应补入？面在哪里停止？支撑是否足够？ | [拓展、验证与局部修复](./surface-analysis) |
| 3. 特征与实体识别 | 哪里是孔、凸台或槽？构成什么实体？ | [特征、实体类型与人工引导](./feature-recognition) |
| 4. 多体分组与闭合 | 哪些面属于同一部件？有限边界能否围成实体？ | [部件分组与闭合](./assembly-reconstruction)、[二维轮廓与投影回退](./projection-fitting) |
| 5. 参数化建模与交付 | 怎样生成可编辑特征并保存交付？ | [特征历史与 B-Rep](./parametric-modeling)、[工作区与编辑](./studio)、[保存与导出](./persistence) |

分割得到的“圆柱面”是几何类型，识别出的“贯穿孔”是结合宿主和材料方向的特征语义。面片、部件、实体和特征历史也分别属于不同层级。模块3、4输出的 `CompoundCandidate` 仍是建模提案，模块5成功提交后才得到模型。

## 与端到端流程的对应

```text
STEP / 真实零件
  → 虚拟拍摄（capture）
  → 图像重建（image-reconstruction）
  → 点云预处理（preprocessing）
  → 1 曲面分割与几何类型拟合（surface-detection）
  → 2 曲面拓展、有限支撑验证与关系（surface-analysis）
  → 3 特征与实体识别（feature-recognition）
       ├─ 直接得到合格候选
       └─ 按条件进入 4 多体分组与闭合／投影回退
  → 5 建模补丁、特征历史与 B-Rep（parametric-modeling）
  → 工作区编辑与持久化（studio / persistence）
```

采集与重建只产出点云和相机清单；点云与曲面只产出证据、面片和关系；识别与装配只产出候选；建模核心才把候选转换为可编辑的特征历史和 B-Rep。任一阶段失败时，上游产物保持不变，错误沿调用方返回。

## 术语约定

- **观测快照**：一次输入的全部源观测、单位和指纹；任何点或单位变化都会使依赖它的分析失效。
- **源点 ID**：客户端原文档行号加一，降采样、离群过滤和修复合并都不会重新编号。
- **曲面证据、有限面片与关系**：证据是拟合出的解析面，面片是该面在观测上的有限连通支持，关系是面片之间的几何假设。
- **候选与建模补丁**：候选是识别结果，仍是提案；只有绑定当前修订并完成原子提交后，才会进入特征历史并重建 B-Rep。

## 使用建议

- 只关心点云转模型时，先读[五个模块总览](./point-cloud-to-cad)，再按问题进入详细页。
- 只关心图像到点云时，读“多视角图片构建点云”三页即可；查数据身份与调用边界时，再读[系统分层](../architecture/system-layers)和[数据契约](../architecture/data-contracts)。
- 想复现一条完整链路，按 [点云到 CAD 快速上手](../getting-started/first-reconstruction) 或 [从多视角图像生成点云](../getting-started/images-to-cloud) 操作。
- 调整阈值前先阅读 [超参数配置](../development/configuration)，确认配置优先级和单位。
- 需要核对回归覆盖时，参考 [阶段契约与回归测试](../validation/contract-tests)。
- 排查失败时先确认当前阶段属于哪个模块，再对照该页的“输入与输出”和“已知限制”，避免把识别候选当成已提交实体。
