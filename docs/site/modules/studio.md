# 桌面工作区与参数编辑

所属主线：[模块5：参数化建模与交付](/modules/point-cloud-to-cad)。本页介绍操作界面；界面中的“识别表面”和“重建 CAD”分别编排不同的几何任务，职责与分支见五个模块总览。

## 职责与入口

本页描述 ParamCAD Studio 桌面端的组织方式和用户可见的参数编辑流程。它不实现几何算法：点云、识别、投影和建模都调用 `core/` 下的库；客户端负责编排任务、维护编辑状态、显示结果并把用户意图转换成结构化命令。

`MainWindow` 是组合根，负责创建控件、命令控制器、停靠面板、菜单和工具栏，连接场景导航与相机显示，并统一呈现日志和状态消息。编辑状态和各功能的信号连接分散在以下控制器：

| 控制器 | 职责 |
| --- | --- |
| `SketchWorkspaceController` | 基准面选择、草图会话/草稿、实体编辑、拉伸/切除、特征删除、重建反馈和相机恢复 |
| `PointCloudWorkspaceController` | 把面板意图路由到点云文档，协调后台拟合与照片重建，保护 CAD 候选提交 |
| `CaptureWorkspaceController` | 截图、照片、环绕拍摄意图，输出设置、镜头列表和批量反馈 |
| `ModelViewController` | 导入/当前 B-Rep 生命周期、STEP 导入导出、模型可见性、纹理和性能捕获 |
| `ProjectController` | 工程动作、状态快照、分阶段恢复、资产生命周期和工程路径 |
| `FeatureEditingController` | CAD 特征参数编辑、语义参照拾取、文字参数预览与应用、撤销/重做状态 |
| `ModelingController` | 建模命令、原子补丁、修订检查、撤销/重做和手动修改保护 |
| `ReconstructionController` | 通过 `QProcess` 启动并监控照片重建流程 |

## 输入与输出

输入：

- STEP/STP、PLY、`.pcad` 工程和点云标注文件；
- Qt 面板上的数值、选项、列表选择、视口拾取和键盘输入；
- 受限中文参数指令；
- 点云与模型文档的当前修订。

输出：

- 视口显示：由 B-Rep 派生的三角网格、点云 actor、草图与基准面 actor、投影预览；
- 建模结果：新特征历史、当前 B-Rep、撤销/重做栈；
- 文件：`.pcad` 工程、STEP 文件、截图和拍摄/重建输出；
- 状态与错误文本：面板消息、控制台日志和状态栏。

客户端不直接保存几何算法的中间状态；识别与后台任务的结果必须通过文档修订校验后才能提交。

## 核心数据结构与依赖

- `PointCloudDocument`：源路径、单位与尺度元数据、观测、选择、删除掩码、集合、关系、撤销历史和单调递增修订；调用方获得只读状态或带原始 ID 的工作点快照。
- `Scene` 与场景树：模型、视口相机和点云三类节点；隐藏保留数据，删除模型清空特征历史，删除点云清空观测与标注。
- `ProjectViewState` 与 `PresentationState`：相机位置/目标/上方向、投影方式、背景、光照、输出尺寸、纹理、对象位移/旋转/缩放/透明度/颜色。
- `ModelingController`：持有 `ModelingCore`、撤销栈和重做栈；每步提交 `ModelPatch`，成功后记录历史。
- `FeatureEditingController`：持有当前文字参数提案，连接特征面板、参照拾取、预览与应用请求。

依赖：Qt 6 Widgets（窗口、面板、模型/视图、文件与 JSON）、VTK 9.7.0（视口、拾取、相机、离屏截图）、OpenCASCADE 8.0.1（B-Rep、三角化和 STEP）。`OcctShapeTessellator` 只负责把 B-Rep 离散为显示网格，原始 B-Rep 不被替换。

## Qt 交互、VTK 视口、语义参照与文字参数编辑

点云属性页分为四页：

1. **选点**：模型交互、单点拾取或三维选择框；Ctrl/Shift 改变选择；框模式可拖面/手柄缩放、拖主体旋转、Shift 拖动平移；可按零基原始点 ID 定位；“扩展一轮”使用原始 PLY 单位半径。
2. **集合**：集合树是唯一编辑目标；右键可编辑名称/模板、追加或替换成员、按模板重建、删除集合保留点或删除集合内点；模板支持长方体、平面、球、圆柱、圆锥和圆环，并显示拟合参数、残差/置信度和分页原始 ID。
3. **关系**：支持平行、垂直、邻近/相邻、相交、同轴、相切、等半径和共面证据；关系是标注和证据，不移动 CAD 几何。
4. **设置**：拟合距离容差、关系距离容差和关系角度容差；距离使用原始点云坐标单位。

CAD 特征编辑：

- 左侧“CAD 特征”列表选择 Box、贯穿孔、圆柱、轮廓体或拉伸后，在“Properties → 特征”编辑。
- Box 显示长/宽/高三个局部尺寸，固定参照为“中心”或六个局部面；选择固定面时只有该面法向尺寸可编辑，其余尺寸禁用。
- 圆柱显示半径和高度，固定参照为底面中心、顶面中心或实体中心；半径始终同心。
- 贯穿孔只显示孔直径，编辑保持世界坐标中的孔轴位置和方向。
- “在视口选择参照面 / 中心”显示所选基元的六个彩色语义面和黄色中心标记，即使基元已被融合；旋转视图拾取面，Esc 取消。拾取通过 `FeatureId + FaceRole` 解析，不依赖布尔结果的面编号；导入 STEP 面或共面归属歧义时退回固定平面。

文字参数编辑：

- 输入上限 512 字符，可写 `#3 的孔直径改为 8 mm`，也可省略编号使用当前选中特征。
- 支持长方体、轮廓体、圆柱和贯穿孔；长方体/轮廓体识别长宽高或 X/Y/Z，圆柱识别半径、直径、高度，贯穿孔识别直径、孔径、孔直径。
- 每个尺寸支持“改为/改成/设为/设置为/增加/增大/减少/减小”；单位支持 mm、cm、m 与毫米、厘米、米，未注明按毫米；百分比只能与增减搭配。
- 一条指令最多修改三个尺寸并附加一个“固定中心/底面/顶面/X-面”等参照；同一尺寸不能重复指定。
- 预览阶段解析目标、单位和参照，生成带 `expectedRevision` 的提案，并在模型副本上完成完整依赖重建；验证通过后才显示“应用预览”。输入、选择、模型修订或编辑状态变化都会使预览失效。

提交与历史：

- 所有手动编辑通过 `ModelingCore::apply()` 原子提交；命令或重建失败时参数和几何一起回滚。
- 成功提交记录撤销栈，最多保留 50 步；`Edit → 撤销 CAD 编辑 / 重做 CAD 编辑` 只作用于当前会话。
- 自动识别产生的特征标记为 `reconstructed`；用户手动修改后标记为 `manuallyEdited`。只要存在“已重建且被手动修改”的特征，模板重建会暂停；显式“重建 CAD”需确认替换。编辑或撤销开始前启动的旧结果会被修订检查丢弃。
- STEP 导入和工程替换会清空 CAD 撤销历史；导入 STEP 的实体没有参数化特征编辑器。

显示变换：

- 对象位移、旋转和非均匀缩放同时作用于实体、草图和基准面，只影响显示。
- 拾取和绘制在生成 CAD 数据前移除该放置变换，因此显示旋转/缩放不会改变模型尺寸。

## 已知限制

- 参数编辑器只覆盖 Box、贯穿孔、圆柱、轮廓体和拉伸深度；球、圆锥、圆环等特征没有同等的图形化尺寸编辑入口。
- 文字指令是确定性受限语法，不能理解自由自然语言、多个目标或拓扑修改；超出语法的输入会被整体拒绝。
- 撤销/重做只保留在当前会话，最多 50 步；`.pcad` 保存参数、参照和手动保护标记，但不保存撤销栈。
- 语义面只覆盖 Box 六面和圆柱底/顶面；导入 STEP 面、其他基元面和任意布尔结果面仍是固定平面。
- 显示位移、旋转和缩放不进入模型坐标，因此不能通过视口变换改变真实尺寸或位置。
- 点云编辑的撤销上限为 20 步，与 CAD 的 50 步历史彼此独立，不能相互回滚。
