# 快速开始

本栏目面向第一次运行 ParamCAD Studio 或第一次把图像、点云接入重建流程的读者。内容对应当前仓库实现（客户端 0.3.18），命令、菜单和参数均取自源码与各模块 README，不描述尚未实现的功能。

阅读前建议先确认两件事：你手上有什么数据（多视角图片、现成 PLY 点云或 STEP 模型），以及你打算做什么（只运行桌面客户端，还是从源码构建、批量跑重建）。本栏目只覆盖从零到第一次得到点云或 CAD 的主路径，算法细节放到「模块手册」和「算法原理」。

## 开始前的准备

- Windows 10/11 x64；使用发布包时不需要安装开发工具。
- 从源码构建需要 Visual Studio 2022、CMake 3.24+、Qt 6.5+、仓库本地 VTK/OCCT SDK，以及 vcpkg 的 `cgal`/`eigen3`。
- 图像重建另需 Python 3 与 COLMAP 4.2.0；完整离线发布包已内置。
- 准备可写的 `outputs/` 目录，拍摄、重建、截图和临时验证结果都会写在这里。
- 若只想验证点云到 CAD，可先使用已有的带单位 PLY，不必先跑图像重建。

## 推荐阅读顺序

1. 先读 **项目介绍**，确认当前支持的长方体组合、加强筋、贯穿孔和独立曲面实体是否覆盖你的零件。
2. 再读 **安装与构建**，把客户端跑起来；只想使用发布包时，可直接看该页的「启动与环境检查」。
3. 如果已有带单位的 PLY，直接进入 **点云到 CAD 快速上手**。
4. 如果只有多视角照片，先按 **从多视角图像生成点云** 得到 `cloud.ply`，再回到第 3 步。
5. 需要修改算法参数或做批量验证时，转到 [超参数配置](/development/configuration)。

只想知道环境是否就绪，可在仓库根目录先执行非递归依赖检查，再启动客户端：

```powershell
& .\deps\verify.ps1
& .\tools\install_pcad.ps1
pcad studio
```

## 阅读约定

- 单位默认按毫米描述；点云是否具有公制尺度由相邻清单或用户确认决定，未知尺度不会被静默当作毫米。
- 源码位置使用行内代码路径表示，例如 `core/reconstruction/reconstruct.py`。
- 运行产物统一写入仓库的 `outputs/` 下，按类型和时间戳分目录。
- 界面菜单同时提供中文和英文，正文给出中文路径，并在括号中标注英文名称。
- 各页面在能力清单或末尾说明已知限制；需要完整能力清单时，以根目录 `README.md` 和各模块 README 为准。
- 具体版本、阈值和默认值以代码、`apps/ParamCAD Studio/config/` 与 README 为准；文档不重复维护易变的数值副本。
- 文档与代码不一致时，先检查当前分支的实现，再更新文档，不按旧截图或旧包描述推断行为。
