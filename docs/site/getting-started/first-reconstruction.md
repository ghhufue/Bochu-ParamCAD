# 点云到 CAD 快速上手

本页按操作顺序介绍导入、重建和编辑。想先了解算法分工，可读[点云转参数化模型：五个模块](/modules/point-cloud-to-cad)：曲面分割、拓展验证、特征识别、多体分组闭合、参数化建模与交付。

## 准备样例与单位

客户端读取 PLY 的点坐标、颜色以及可选的 `nx/ny/nz` 法向，支持 ASCII、binary little-endian 和 binary big-endian 三种编码。点云可以来自 `core/reconstruction` 的 COLMAP 输出，也可以来自其他扫描或测量工具。

尺度信息按以下顺序从点云旁边的 JSON 读取：

1. `workspace/reconstruction.json`；
2. 同目录的 `reconstruction.json`；
3. 与 PLY 同名的 `<文件名>.json`。

清单中的 `unit` 识别为 `mm`、`m` 或 `arbitrary`。米制点云在预处理时换算为毫米；没有公制元数据时，客户端不会猜测尺度，而是在点击「重建 CAD」后弹出确认框，明确询问是否按「1 个源单位 = 1 毫米」继续。选择「否」会取消本次重建，模型保持不变。

导出工作点云时，客户端会在新 PLY 旁写一份同名 `.json`，只包含 `unit` 字段。需要注意：导出会压缩点 ID，标注仍属于原始点云，应保留原始 PLY 再载入标注。

本地已有性能验证输出时，可直接使用例如：

```text
outputs/performance-validation-box-through-hole/dense_cloud.ply
outputs/performance-validation-l-bracket-gusset/dense_cloud.ply
```

## 导入点云

使用 **文件 → 打开点云…**（英文界面为 **File → Open Point Cloud**）选择 `.ply` 文件。也可以把单个本地 PLY 或 STEP/STP 文件拖入窗口；一次只接受一个文件，文件夹、远程 URL 和多文件拖入会被拒绝，源文件不会被移动。

导入后：

- 点云即使远离原点也会以自身为中心显示，视口的中键旋转、右键平移和滚轮缩放保持可用；
- **Properties → 点云** 顶部显示源文件、单位、有效点/原始点/已删除点数量以及当前选择；
- 在「集合」页或三维视图中点击已拟合的面，可以高亮整个集合；
- 预处理、曲面证据和关系都通过源点 ID 引用同一份观测，降采样不会把 ID 改成采样后的序号；
- 点云编辑最多保留 20 步撤销，选择手势本身不会推进文档修订号。

打开 PLY 后，客户端读取点云并显示原始点。点击 **Properties → 点云** 底部的「识别表面」，可从未归属点中识别曲面并保留已有集合。

左侧 **CAD 特征** 列表与 **Properties → 点云** 的四页（集合、关系、设置、交线与边界）共同构成点云工作区。「交线与边界」可以检查一个平面的轮廓，也可以勾选多个面来拟合交线。曲面关系作为重建证据和点云标注。

中央视口默认是「主视图」。「工具 → 参数化建模」可在独立标签页中查看当前实体并调整参数；「交线与边界」的交线预览也使用独立标签页。只有当前标签页持续渲染，相机和截图都作用于当前活动视口。

## 重建与编辑

确认工作点云非空后，执行 **工具 → 重建 CAD**（**Tools → Reconstruct CAD**）。重建在后台线程运行，进度和取消按钮位于点云工作区；**工具 → 取消 CAD 重建** 会在计算阶段之间生效，不会中断正在执行的几何库调用。实体推断期间，客户端会以半透明叠色显示已验证曲面和临时实体候选；预览只用于观察，不会修改点云或模型，取消、完成或修订变化时自动清除。

重建任务的输入是一份观测快照，包含工作点云的坐标、法向、单位、锁定模板和手动关系。任务结果按来源分为三个分支：

| 分支 | 触发条件 | 结果 |
| --- | --- | --- |
| 常规识别（实体推断） | 没有手动模板约束 | 从 `SurfaceScene` 生成候选：观测闭合壳、平行端盖拉伸，以及由拉伸得到的通孔/盲孔切除 |
| 模板引导 | 存在锁定的集合模板 | 按指定平面、长方体、球、圆柱、圆锥或圆环约束整体重建 |
| legacy 装配分离 | 仅离线 CLI 显式 `--legacy-assembly` | 分离与闭合部件；仍开放的候选在启用回退且满足条件时尝试投影拟合 |

默认分支只使用实体推断，不会在失败后自动回退到 legacy 装配；Studio 和在线命令不提供旧装配入口。离线需要旧链时，显式执行 `pcad reconstruct cad --offline ... --legacy-assembly`。分离出候选但没有验证闭合实体时，状态栏和日志会报告「未生成新的 CAD，已有模型保持原状」，候选仍显示在点云集合中。若表面检测有结果但实体闭合未通过，客户端会保留并显示检测面片，并提示「表面检测成功，实体闭合未通过」，已有模型保持不变。若点云或模型在任务运行期间被修改，本轮结果会被丢弃。

同一份点云再次识别或重建时会复用匹配的本地缓存；报告和日志可查看命中情况。**设置 → 清理点云缓存…** 会删除全部缓存，下次需要时重新计算，详见[本地重建缓存](/modules/persistence#本地重建缓存)。

编辑已生成的特征：在 **CAD 特征** 中选择 Box、贯穿孔或圆柱，进入 **Properties → 特征**。

- Box 尺寸沿特征局部 X/Y/Z；固定中心时对称缩放，选择某一语义面时只改变该面的法向尺寸；
- 贯穿孔只编辑直径，世界坐标中的孔轴保持不变；
- 圆柱可编辑半径与高度，高度支持固定底面、顶面或中心，半径保持同心；
- **应用** 以一次原子提交写入特征历史，**取消** 恢复待编辑字段；命令或重建失败时参数与几何一起回滚；
- **编辑 → 撤销 CAD 编辑 / 重做 CAD 编辑** 只保留在当前会话，最多 50 步；`.pcad` 保存已提交尺寸，但不保存撤销栈。

编辑集合或载入标注后，可以点击「重建 CAD」或右键选择「按此集合模板重建」应用这些修改。在集合页新增或编辑选区时，如果选区至少有 20 个点、点云单位已确认且当前没有受保护的重建特征，客户端会自动请求一次重建；已有重建在运行时，客户端会先请求取消并在结束后重新启动。点云尺度未知时不会自动启动，而是提示手动重建并确认尺度假设。若已有手动修改过的重建特征，客户端会先询问是否替换。替换后原有的手动尺寸调整会丢失。导入 STEP 或替换工程会清空 CAD 撤销历史，导入的 STEP 几何没有参数化特征编辑器。

## STEP 导出与结果检查

执行 **文件 → 导出 STEP…**（**File → Export STEP...**）写出当前原生 CAD 几何，坐标使用模型坐标、单位为毫米。保存对话框接受 `.step` 和 `.stp`，缺少扩展名时补 `.step`。没有实体或已关闭模型时该入口不可用；选择文件期间实体发生变化会拒绝本次导出，可对新模型重新导出。

导出内容只包含 CAD 几何，不写入相机/显示变换、纹理、点云标注或可编辑特征历史。需要保留这些内容时使用 **文件 → 保存**（`Ctrl+S`）写 `.pcad` 工程。

检查结果时建议依次核对：

1. **Properties → 特征** 中的拟合参数与尺寸，而不是只看视口外观；
2. 导出 STEP 后重新导入，确认边界框尺寸、孔直径和实体数量；
3. 用日志中的长方体、棱柱、通孔和曲面实体数量与表面覆盖率判断是否漏识别；
4. 需要复现实测点云时，可在 `apps/ParamCAD Studio` 目录下把带毫米尺度的 PLY 交给验证程序：

```powershell
& "./build/msvc-debug/Release/cad_reconstruction_task_test.exe" `
  "../../outputs/performance-validation-box-through-hole/dense_cloud.ply"
```

已知限制：默认自动路径只支持平面闭合壳与双端盖拉伸，缺盖面、曲面实体、凸台和通用凹槽没有候选来源；需要旧装配链的专用闭合能力时，只能使用离线 `--legacy-assembly` 或 `pcad assemble` 做对照。盲孔、凸台、孔槽和多体分组等既有能力仍依赖宿主、端面、材料方向和有限边界等观测。各路径的条件见[五个模块总览](/modules/point-cloud-to-cad)及[项目介绍](/getting-started/introduction)。
