# 带阶梯盲孔的 U 型槽件

外形为 100 × 70 × 65 mm，底板厚 20 mm，两侧壁厚 12 mm。槽沿 X 贯通，
槽底位于 Z=20 mm，净槽宽 46 mm、深 45 mm。

| 特征 | 尺寸与位置（mm） |
| --- | --- |
| 槽底阶梯盲孔 | 孔口中心 (62, 35, 20)，沿 −Z。入口 Ø24 深 4，小径 Ø16 总深 12，孔底位于 Z=8 |
| 侧壁通孔 | 孔口中心 (31, 0, 46)，沿 +Y，Ø12，只贯穿 Y=0..12 的侧壁 |

`model.step` 经 Studio 回读为 1 个实体、12 个平面和 3 个圆柱面。
`case.json` 记录槽底、孔肩、盲孔底与侧壁孔的标准尺寸。盲孔底需要
单独验收，端到端精度待测。
